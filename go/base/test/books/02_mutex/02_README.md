## 锁的类型有哪些？作用是什么

| 锁类型   | 适用场景         | 核心特点                  |
|----------|------------------|---------------------------|
| 互斥锁   | 临界区保护       | 独占、不可重入            |
| 读写锁   | 读多写少         | 允许多个读线程            |
| 可重入锁 | 递归或嵌套锁     | 同一线程可重复获取        |
| 自旋锁   | 短耗时操作       | 避免线程切换，消耗 CPU    |
| 乐观锁（CAS）   | 冲突概率低       | 无锁，提交时检查          |
| 分布式锁 | 跨节点协调       | 基于中间件实现            |
