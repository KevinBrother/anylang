# process

## 如果作为 deamon 程序，应该监听 exit 还是 close 呢？

- exit: 当子进程本身终止（退出）时触发,仅表示子进程的主程序已经结束，但其打开的文件描述符、stdio 流（如 stdout/stderr）可能尚未关闭。
- close: 当子进程终止且所有与其关联的 stdio 流（stdin/stdout/stderr）都已关闭时触发。表示子进程完全结束，所有资源已释放（比 exit 更彻底）。
- daemon 程序（长期运行的服务进程），核心需求是监控子进程是否意外退出，并在退出时自动重启以保证服务可用性。对于 daemon 程序，我们更关心 “进程是否已经停止运行”（exit 能直接告诉我们），而不是 “资源是否完全释放”（close 的意义）。
